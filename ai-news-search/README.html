ai-news-search

Codex skill for collecting, organizing, and summarizing the latest AI news from the last 7 days (default window) across public sources, RSS/Folo, GitHub, and X/Twitter, then producing a source-linked brief grouped by topic, ending with trend recommendations.

Structure

PathPurpose
SKILL.mdSkill instructions and full workflow.
references/ai-radar-sources.mdOfficial blogs, RSS feeds, and feeds observed in local Folo.
references/x-high-signal-accounts.txtHigh-signal X accounts (exported from local Folo).
references/github-hot-repos.mdGitHub radar keywords, ranking, and cross-check rules.
scripts/Collection and report helpers (see below).

Scripts

  • export_folo_subscriptions.py — placeholder export of Folo RSS subscriptions.
  • export_X_cookies.py — export X cookies from Chrome/Edge for authenticated collection.
  • validate_X_cookies.py — validate cookie file (required keys, expiry).
  • ensure_X_cookies.sh — one-shot: validate → login (CDP) → export → validate.
  • open_X_login_cdp.sh — open X login in a CDP-enabled browser profile.
  • prepare_X_search.py — build X search queries from keywords/accounts.
  • github_hot_ai_repos.py — GitHub Search API radar (keyword sweep).
  • github_trending_fast_risers.py — fast-riser ranking + trending page fallback.
  • generate_report.py — render collected items to Markdown/HTML.
  • template.md / template.html — one-page report templates.

Usage

# GitHub radar
python3 scripts/github_hot_ai_repos.py
python3 scripts/github_trending_fast_risers.py --hours 24

# X collection (needs login once)
./scripts/ensure_X_cookies.sh
python3 scripts/prepare_X_search.py --keywords "agent,MCP" --days 2 --open

# Report from collected items (JSON)
python3 scripts/generate_report.py items.json report.md
python3 scripts/generate_report.py items.json report.html --html
